# Writing 训练功能 · 本轮实现

沿用现有像素档案设计、统一 Store 和 `ielts-workspace.data.v2`，不修改 Home、Reading、Synonym Review 数据。

## Task 2

七步保持：原题 → 中文逻辑 → 检查 → 中文修改 → 英文框架 → 英文纠错 → 可选全文。

中文只显示当前段落（开头 / Body 1 / Body 2 / 结尾）；主体段包含观点、原因、展开与结果、例子。初稿和修改稿分别存储，切换步骤、提交检查或显式保存时保留历史快照。

保留现有真实反馈接口，AI 区域按需展开。自动检查不可用时，可以逐项**人工核对**并继续；不会生成分析文字，不会将人工确认标记为 AI 通过。确认与稿件的完整输入快照绑定，改稿、改题型或撤销检查项后立即失效。中文确认后才能转英文，英文确认后可选写全文，也可以只保存框架。

《论点库1》为论点和逻辑素材，未发现可核验完整 IELTS 原题。此前九道改编题不再作为原题池返回。原题池支持填写话题、完整题干、可追溯出处及本人核对确认；仅已确认有出处的记录参与随机抽题，优先轮换不同话题、较少训练的话题，同题文本规范化去重。题目编辑 / 删除不改变已有训练的题干和出处快照。未登记出处的旧题目保留，需核对后才能参与原题抽取。

《浓缩版观点库》本轮新附件与上一份 SHA-256 完全一致，没有重复导入。本地英文辅助仅保留少量带 PDF 页码的原文完整句，**在英文纠错阶段**由用户主动检索。它们是资料摘录，不算用户已经掌握的观点，不自动写入个人知识库。原句照录，包括原资料的语言局限，使用前需核对语法、搭配与语境。原有服务端资料的跨片段精确去重保留，不宣称已人工审核全库语义去重。

## Task 1

Data Charts 的动态和静态子类是两套独立训练：不同来源、关键词、分析任务、题图和草稿。三个一级类别保留。

已读取两份讲义，按原句摘录附 PDF 页码，中文为单独标注的学习译文；未改变原句。在原句数据与图像近似值不完全一致时单独提示，以图为准，不暗改引文。9 个原句的表格栏位已对照 PDF 图像阅读核验。

题图从讲义内嵌图像**直接提取**，不是重新绘制：动态图为 CO₂ 四国图，静态图为石油生产消费图。没有整篇范文作为默认答案。静态图原题来自讲义作业，不额外声称已核验历年真题的场次。

六步训练含原句展开、关键词解释、填空核对、替换、造句、看图分析、四段独立写作、人工修改清单。填空只核对是否与源句一致，不冒充语法或语义判分。可将需要复习的句子经确认存入个人错误本。

当前附件中没有《大小作文急救模板.pdf》：因此尚未实现该文件的完整模板呈现。Process / Maps 不再使用前轮自编模板或 DEMO 图代替来源；可录入本人已有英文模板、中文解释、出处，核对后按六步练习。支持上传 PNG/JPG/WebP 实际题图（最大 1MB）与题干，作为浏览器本地资料保留。没有题图和题干时不能把分析步骤算作完成。

`public/writing` 仅包含两份本轮讲义用于练习的图像摘录，不包含整份 PDF，也没有用户个人学习成绩。动态图原题图片保留备查。没有推送或发布。

## 保存与知识库

刷新和退出返回后，恢复 activeId 对应的科目、子类、步骤和草稿。旧 Writing 六步作文 step 5 兼容为新版 step 6（第 7 步），旧稿件字段和所有历史条目保留。

训练输入不会自动生成知识库条目。表达与错误须通过人工勾选确认后收录，保存来源训练 ID / 步骤，支持编辑、查找、待复习 / 已掌握、每次复习时间与历史、回溯来源。编辑已掌握条目后回到待复习。旧版条目无 `confirmedAt` 时显示待确认，不计入已确认知识库。重复文本不会重复收录。删除训练时一并删除关联表达和错误；其他训练与 Reading、Vocabulary 等数据保持完整。

存储失败时保留页面里的未保存稿件并提供重试，明确提示不要刷新；**浏览器刷新仍只能恢复上次成功保存的数据**。

## 验证

- `npm run test:writing`：版本绑定、人工核对、原题轮换、旧数据兼容与资料分类。
- `npm run test:writing:browser`：离线完整七步、自动保存和恢复、句库确认与复习、题目删除保留来源快照、真实讲义图像、动静态分别练习、自备题图与个人模板、删除。
- `npm run test:writing:ai`：仅验证保留的真实 HTTP 适配器及错误分支，不消耗实际模型调用。
- Reading / Discovery 单元及浏览器回归继续执行；TypeScript 与生产构建。
