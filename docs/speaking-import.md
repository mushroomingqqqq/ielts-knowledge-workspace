# Speaking 题库导入与训练

## 来源与架构

来源为用户上传的《2026年9-12月雅思口语题库完整版20260916_20260916174315.pdf》，66 个物理页，SHA-256：`5de743af4ac352eddba1b252a0385d9372867bbee5b3feec76ab34533826bcef`。

本模块先完成题库导入和主页面，再扩展三个 Part 的训练。全部沿用现有颜色、IBM Plex Mono、像素标题、纸张卡片与统一 Store，不重建网站，也不新增 Key 设置。

- `scripts/import-speaking.py`：使用 Poppler `pdftotext -layout`，按物理页提取，正文从第 4 物理页开始；题干、中文、提示词、参考答案和 Part 3 分开导入。
- `public/speaking/bank.json`：结构化只读题库，包含 topics / questions / source pages。原 PDF 本身未上传 GitHub；页面支持按物理页查看保留的原页文本。
- `src/lib/speaking.ts`：个人回答、版本、计时、复习、收藏与故事关联模型。
- `Workspace.speaking`：可选扩展，保留原 localStorage key 和已有数据。旧工作区不需要破坏性迁移。
- 原有 `Note.recordType=story` 复用为个人故事实体，一份故事通过 `storyLinks` 关联多个导入 Part 2 ID。编辑不变更 ID；删除故事清理新旧关联，不删题库和练习。
- `server/speaking-core.mjs` 和 `/api/speaking/feedback`：复用现有 BYOK 会话、CSRF、限流和固定服务商适配器。

## 已发现的原文问题

- 目录、印刷页码和物理页不一致：例如物理第 35 页印刷为第 34 页。界面同时显示两者，以物理页为回查基准。
- Vegetables 的“纯题目”和“答案版”问法／序号不完全对应；如 `Where do you usually buy vegetables?` 没有匹配参考答案，不挪用其他问法答案。
- Politeness 原分组含 `Would you choose to wear sneakers when you are not exercising?`，保留源分组并提示，不擅自改题或改组。
- “吵闹的地方”缺少 Part 3 起始标签；“尊敬的老人家”有两条延伸题写在标签之前。按原文问句边界整理，保留异常标记。
- `What would make people feel less stressed having more time or more` 原文疑似截断，照录并标记，不补写；从默认随机与 AI 分析中排除。
- 原文的拼写、语法、答案标签与事实内容不作认证。不会将文件里的命中率、Band 标签当成本网站预测结果。

全部题干、提示词和参考答案通过逐条源页文本匹配校验。原文既是训练来源，也可能有错误；用户仍可主动回看物理页文本。

## 页面与训练

1. **Part 1 / Part 2 / Part 3 主页面**：话题档案卡、原分类筛选、全站搜索、收藏／未练习／已提交／需要复习／已掌握／口语错题筛选、随机与薄弱加权抽取。
2. **单题训练**：默认只显示题目，不展示答案；用户输入自己的英文回答，或 Part 2 本人确认已完成口述后，才可主动查看该问法的来源参考或原页文本。刷新后参考区默认收起，暴露记录保留。
3. **Part 1**：回答、修改稿、个人问题与改法、版本、收藏、复习、BYOK 文字纠错。
4. **Part 2**：60 秒准备 → 120 秒口述，可暂停、继续、重置；保存真实 deadline，刷新后按时间恢复。计时不等于实际开口，不会自动计作完成；用户可本人勾选已口述并提交。支持准备笔记、文字稿与多题共用个人故事。
5. **Part 3**：中文逻辑 → 英文观点／理由／例子 → 修改和语言纠错；提供所属原 Part 2 导航，不自动提前填英文观点。
6. **个人故事库**：与旧共享故事共用实体，支持新增、编辑、删除和多个 Part 2 关联。
7. **练习历史**：保留回答、阶段修改、AI 反馈版本及是否曾看参考。收藏和草稿不计已提交；话题进度按当前 Part 全体题目统计，不因收藏筛选而改变分母。
8. **已有口语笔记**：原 Library 及其功能完整保留。旧笔记不伪装为题库答题进度；旧共享故事可关联导入题卡。

“薄弱”来自本人标记需要复习的记录和话题，不是 AI 能力预测；已掌握仍可能抽查。改动已掌握回答会回到需要复习。口语错题保存在本模块“口语错题”筛选，不改动 Reading／Listening 的统一错题页。

## AI 与限制

Speaking 只使用 AI Settings 当前用户的会话密钥，不设置或读取网站所有者模型密钥。后端按题库 ID 和版本查真实题干，不接受替换后的任意题目文本，不发送资料参考答案作为生成目标。Part 3 可先进行中文逻辑检查，再纠错英文。

AI 输入只包含题目／提示词和用户主动提交的文字。反馈引用原话、给局部改法及原因，不自动生成完整回答、不创造个人经历，不自动更新掌握状态；修改后的输入与旧反馈快照比较，旧结论明确标记过期。真实返回自动保存版本，缺 Key / 网络错误不生成模拟分析。

当前口述训练没有录音、自动转写或语音评分。AI 自然度和连贯性检查只针对用户录入的文字稿，不能据此判断真实发音和口述流利度。成功链路使用明确 TEST 上游验证，未使用真实用户 Key 进行计费调用。
